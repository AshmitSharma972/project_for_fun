# Eight-step demo

1. Open the dashboard with an empty memory bank and show its honest empty state.
2. Post a payment timeout incident through `POST /incidents`.
3. Analyze it and show the runbook-only fallback when history is absent.
4. Submit an engineer-verified root cause and resolved outcome.
5. Show the stored feedback and increased recorded-outcome count.
6. Post a similar payment timeout incident.
7. Analyze it and open the Memory Evidence Panel to show retrieved history.
8. Run Replay Lab and show failed-fix warnings when recorded evidence supports them.
