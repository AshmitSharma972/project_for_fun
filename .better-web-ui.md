## Design Context

### Users
On-call engineers and hackathon judges need to assess an incident quickly,
verify what evidence informed a recommendation, and record an engineer outcome.

### Brand Personality
Calm, evidence-led, operational. The interface should make uncertainty visible
without creating noise or implying autonomous remediation.

### Aesthetic Direction
Light, warm-neutral operational workspace with restrained rust/red severity
accents, mostly square surfaces, and strong editorial hierarchy. Avoid neon,
glowing dashboards, generic metric-card grids, and terminal clichés.

### Implementation Defaults
Streamlit only; the UI consumes FastAPI HTTP endpoints and never accesses
Hindsight directly. This is a new Streamlit surface with no component library.

### Design Principles
- Make memory evidence the visual center of incident analysis.
- Use status color only after hierarchy, labels, and wording already communicate state.
- Keep one clear next action: review, approve, or submit verified feedback.
- Show empty and unavailable states honestly.
